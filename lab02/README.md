### Задание 5 **(3)**
*Рассмотрим следующую программу на языке Python.*
```
print(*map(sum,zip(
    *[map(int,input().split()) for i in (1,2,3)]
    )))
```
Ключевые слова: for, in.
Идентификаторы: print, map, sum, zip, int, input, split, i.
Литералы: 1, 2, 3.
Операторы: *, .
Разделители: (, ), [, ], ,.

i — это временная переменная цикла
Имена функций: print, map, sum, zip, int, input
Имена методов: split

print: принимает в качестве аргументов результаты работы map.
map: принимает два аргумента: функцию sum и итерируемый объект.
zip: принимает в качестве аргументов три списка.
int: принимает один аргумент - строку, полученную от input().split().
input: считывает строку с клавиатуры.
split: разбивает строку по пробелам.
sum: принимает один аргумент - кортеж из трех чисел.

что делает программа:она трижды запрашивает у пользователя ввод строк с числами. Затем преобразует эти строки в три списка чисел и поэлементно складывает их. В конце выводит три полученные суммы на экран
### Задание 6 **(2)**
*Как можно записывать комментарии на С++?*
Однострочные комментарии: начинаются с //
Многострочные комментарии: начинаются с /* и заканчиваются */

*Какие из приведенных ниже примеров являются синтаксически неверными (вызывают ошибки при трансляции)?
Почему? Как работают синтаксически верные примеры?*
```
cout<<"Hello /* Это комментарий */ world";
```
верно
```
// /*
 Это комментарий
*/
```
верно
```
/* Я комментирую программы /* комментарий */ */
```
неверно. В C++ запрещены вложенные многострочные комментарии. Компилятор видит первый /* и начинает игнорировать всё.
```
// Я комментирую программы /* комментарий */  
```
верно
```
/* Я комментирую свои программы
// Это комментарий до конца строки */
*/
```
неверно.Комментарий начинается с /* и заканчивается на первой встреченной */. Всё, что идет дальше, становится кодом.
### Задание 7 **(4)**
*Найдите в стандарте С++*

[http://www.open-std.org/jtc1/sc22/wg21/docs/papers/2017/n4659.pdf]

*в приложении* **A.5** *формальные синтаксические правила для 
инструкций циклов* **iteration-statement.** *Опишите на естественном языке каждую строчку
из этих правил. Для каждой строчки из правила приведите короткий пример фрагмента программы,

**Формат ответа.**

*Как видно из правил, есть ... (указать число) инструкции циклов.
Первый вид "--- цикл ...(название), который сответсвует строке правила*

*... (переписать строку из правила)*

* Формат записи (по правилу): ключевое слово* **<<while>>**, *в круглых скобках условие* **<<condition>>**,
